# gitws Implementation Plan

**Goal:** Build a small, open-source CLI that manages named Git repositories,
fixed-commit isolated workspaces, and disk usage without coupling to AI or CI.

**Architecture:** Python standard library CLI. A TOML-like JSON state file maps
aliases to canonical source paths and external bare mirrors. Workspace records
are JSON files under the gitws state directory; Git remains the source of truth
for commits and submodules.

**First version:** repository registration, remote sync, safe source checkout,
detached worktree creation, recursive submodule checkout, listing, removal,
size reporting, and conservative cleanup.
